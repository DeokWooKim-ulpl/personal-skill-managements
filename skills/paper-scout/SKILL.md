> ① 사람의 결정·입력 최소화(모든 설정에 기본값, 입력은 체크박스 위주) ② 소통 창구를 `오늘할일.md` 단일 파일로 고정 ③ 미보유 장비 구매 제안(가격·이유·활용 논문) 추가 ④ "입력 없으면 대기" 규칙 명문화.
>
> **v0.2 대비 v0.3 추가 사항 (신규 기능 통합)**:
> ⑤ **주제별 1:1 상세 설득 리포트 (`ideas/reports/Report_I-NN_*.md`) 추가**: 제시한 아이디어가 $N$개(예: 4개)이면 요약 보고서 외에 각 아이디어마다 하나씩 총 $N$개의 상세 리포트(각 **최소 40페이지 이상**)를 개별 파일로 작성함.
> ⑥ **`detail-references` 규칙 엄격 준수**: 상세 리포트 내 모든 주장·수치·수식에 등장 순서대로 `[1]`, `[2]`, `[1, 2]` 인용 번호를 매기고, 하단 References에 참고문헌 원문 문장·수식·표 데이터 직접 발췌(Verbatim) 및 정확한 위치(페이지, 절, 식, 그림 번호)를 상세히 기입하여 할루시네이션(사기) 여부를 즉시 검증할 수 있게 함.
> ⑦ **선행 연구 그림(Figure) 캡처 및 전용 폴더 영구 관리**: 이전 연구 결과의 그림·그래프 캡처본을 `_paper-scout/ideas/reports/figures/I-NN/` 폴더에 별도 저장하고 마크다운 이미지 경로로 삽입하여 마크다운 파일을 열어도 그림이 깨지지 않고 그대로 유지되도록 관리함.
> ⑧ **생소한 개념 해설 및 독자 설득 구조**: 생소한 개념이 무엇인지 읽으면서 바로 이해할 수 있는 친절한 상세 설명과 함께, 누군가 읽었을 때 *"음! 이렇게 하면 이전 연구결과와 차별성이 있어서 논문이 되겠군!"* 하고 납득할 수 있는 선행 연구 대조 매트릭스·심사위원 방어 논리를 포함함.
> ⑨ **10페이지 분량 한국어 서술식 논문 원고 (*Optics Express* 양식, 빈칸 채우기형) 포함**: 각 상세 리포트 안에 꼭지형식(음슴체)이 아닌 **한국어 서술식 문장**으로 작성된 10페이지 분량의 *Optics Express* 양식 논문 원고를 포함하며, 실제 데이터 그림 자리에 **어떤 조건에서 어떻게 찍은 무슨 데이터가 들어가면 좋은지** 빈칸 채우기 가이드를 상세히 제시함.
> ⑩ **자료 조사 진행 중(미수렴 구간) 리포트·원고의 동적 갈아엎기**: 논문 개수가 수렴하지 않아 조사가 계속 이어지는 동안 새로 다운로드한 논문이 기존 아이디어와 상충(이미 사전에 보고된 내용)되면, 설득용 상세 리포트와 10페이지 논문 원고를 즉시 새로운 방향성으로 전면 재작성(Overhaul)함.
> ⑪ **단기 고속 수렴형 문헌 조사 (Fast-Track Literature Convergence — 1~2일 / 2~3회차 내 조기 수렴)**: 하루 한 번(15시) 다운로드에 맞춰 조사가 질질 끌리지 않도록, ⓐ 1회차에 소주제 전 영역 병렬 탐색 + 시드/리뷰 논문 양방향 인용망(Backward/Forward Snowballing) 일괄 스캔, ⓑ 웹에서 전문 열람 가능한 오픈액세스(OA/arXiv/PMC/MDPI) 논문은 AI가 대기 없이 즉시 자체 분석·등록하고 유료(Paywall) 핵심 논문만 15시 다운로드용으로 압축 요청, ⓒ 15시 다운로드·제출 확인 즉시 받은 논문들의 참고문헌을 당일 연쇄 스캔(Same-Day Chained Search), ⓓ 인용망 수렴률(Citation Closure) ≥ 80% 도달 시 10사이클을 기다리지 않고 **2~3회차(1~2일) 만에 즉시 조기 포화 판정**함.
> ⑫ **순수 마크다운(`.md`) 원본 저장 강제 (Google Docs 자동 변환 원천 차단)**: Google Drive API(`drive:create_file`) 호출 시 `mime_type: "text/markdown"`이나 `text_content`를 직접 전달하면 구글 드라이브가 파일명에만 `.md`를 남긴 채 내부 포맷을 구글 독스(`application/vnd.google-apps.document`)로 강제 변환함. 이를 원천 차단하기 위해 모든 `.md` 파일은 반드시 **로컬 VM 디스크에 `.md` 파일로 먼저 작성한 후 `base64_content: "file:///..."` 경로와 `mime_type: "application/octet-stream"`(`text_content`는 생략)으로 업로드**하여 순수 마크다운 파일(`fileExtension: "md"`)로만 저장함.

## 4. 초기 설정 (사람 입력 = 주제 한 줄) (v0.2 원문 그대로 유지)

1. 첫 실행 시 `오늘할일.md`를 생성, 4절 "주제"만 비워 둠. 루트 폴더는 연결된 폴더로 자동 지정, 기존 분류 폴더 구조는 스캔해서 `config.md`에 자동 기록.
2. 주제 입력 + 제출 → AI가 키워드·제외어·연도 범위·소주제 묶음을 **스스로 제안해 config.md에 씀**(사람은 수정 가능, 안 해도 됨).
3. 장비 DB는 인터뷰 대신 **추정 후 확인** 방식:
   - 주제 논문들의 Methods에 자주 나오는 장비를 뽑아 후보 목록 생성
   - `오늘할일.md` 2절에 하루 3~5건씩 체크박스로 물음 (한꺼번에 몰아 묻지 않음)
   - 답변은 `lab_inventory.md` 표(분류 / 품목 / 사양 / 보유 ✔✘대여 / 비고)에 누적. 미확인은 "미확인"으로 두고 아이디어 보고서에서는 "확인 필요"로 표시
4. 예약 작업 2개 자동 생성(09:00 작성, 3시간 간격 확인). 로컬 장치 필요 + 삭제 권한 1회 승인(이것만은 앱에서 승인 필요).

## 5. 포화 판정 (자동, 기본값) (v0.2 원문 그대로 유지)

- 지표: 최근 3사이클 신규 relevant 편수, 신규 후보의 라이브러리 중복률, 소주제별 편수.
- 기본 기준: 3사이클 연속 신규 ≤ 직전 10사이클 평균의 20% **AND** 중복률 ≥ 70% → 포화. 이후 조사 주 1회, 아이디어 단계 자동 진입.
- 기준은 `config.md`에 있고 바꾸고 싶을 때만 수정. 포화 전에도 사람이 `오늘할일.md` 5절에 "아이디어" 또는 "상세리포트"라고 쓰고 제출하면 즉시 실행.

### 5.1 문헌 조사 조기 수렴(Fast-Track Convergence) 4대 가속 규칙 [문헌 조사 업데이트]
하루 1회(15:00 코어타임) 다운로드 환경에서 문헌 조사가 수일~수주간 질질 끌리는 현상을 방지하고 **2~3회차(1~2일) 내에 빠르게 수렴**시키기 위해 다음 4가지 문헌 조사 규칙을 적용한다:
1. **1회차 전방위 그물망 탐색 (All-at-Once Seed + Citation Sweep)**:
   - 키워드를 하루에 조금씩 나누어 검색하지 않고, **첫 조사 회차에서 모든 소주제(`S1`~`Sn`)의 핵심 고전 원전(Root), 최다 피인용 방법론 논문(Trunk), 최근 3년 내 최신 SOTA 논문(Leaf), 그리고 최신 리뷰 논문(Review)을 한꺼번에 병렬 탐색**한다.
   - 폴더에 이미 있는 논문 및 1차 발굴 논문의 **참고문헌 목록(Backward Snowballing)과 피인용 목록(Forward Citation)**을 첫날 즉시 교차 스캔하여, 해당 주제의 핵심 논문 풀(Pool)을 1~2회차 내에 일괄 포착한다.
2. **오픈액세스(OA) AI 자체 소화 및 유료(Paywall) 핵심 논문 집중 요청 (Zero-Wait OA Ingestion)**:
   - 검색된 후보 중 웹/arXiv/PMC/MDPI/Optica OA 등을 통해 전문(Full-text)을 즉시 읽을 수 있는 오픈액세스 논문은 사용자 다운로드를 기다리지 않고 **조사 단계에서 AI가 직접 전문을 읽어 노트(`notes/`), `library_index.md`, `gaps.md`에 즉시 반영**한다.
   - 사용자가 15:00에 다운로드해야 하는 `requests/요청_*.md`에는 **기관 구독(Paywall)이 필수적이면서 아이디어 성립·기각 판정에 결정적인 핵심 논문(회차당 5~10편 이내 정예화)**만 엄선하여 올린다.
3. **15:00 다운로드 직후 '당일 연쇄 조사(Same-Day Chained Snowballing)'**:
   - 사용자가 15:00경 논문을 다운로드하고 `제출`을 체크하면, 다음 날 09:00까지 기다리지 않고 **당일 오후(15시/18시 확인 회차)에 즉시 새로 들어온 PDF들의 References 섹션을 전수 스캔**한다.
   - 여기서 새로 발견된 필수 미보유 논문(2차 Snowballing)이 있으면 당일 즉시 요청서에 반영하고, 더 이상 새로운 핵심 인용 논문이 나오지 않으면 그날 바로 조사를 종결한다.
4. **2~3회차 조기 포화 판정 기준 (Fast-Track Saturation Criterion)**:
   - 기존 장기 기준(3사이클 연속 신규 ≤ 10사이클 평균의 20% AND 중복률 ≥ 70%)에 더해, 아래 **조기 수렴 조건**을 만족하면 회차 수와 무관하게 **즉시 포화(수렴 완료)로 판정**한다:
     - **조건 A (소주제 커버리지 충족)**: 설정된 모든 소주제(`S1`~`Sn`)별로 원천 이론 논문과 최신 비교 기준선 논문이 최소 2~3편 이상 확보됨(총 라이브러리 15~25편 수준).
     - **조건 B (인용망 폐쇄율 Citation Closure ≥ 80%)**: 최근 다운로드된 논문들의 핵심 참고문헌(관련 주제 인용 논문) 중 **80% 이상이 이미 `library_index.md`에 보유되어 있거나 기요청/기검토 목록에 포함**되어 더 이상 아이디어의 결론을 뒤집을 미지의 핵심 선행연구가 나오지 않음.
   - 조기 포화 판정 즉시 일일 다운로드 요청을 멈추고(주 1회 모니터링 모드로 전환), 확보된 문헌 전체를 바탕으로 **주제별 40p+ 상세 리포트 및 10p 논문 원고 완성**에 화력을 집중한다.

## 6. 아이디어 요약 보고서 (`ideas/아이디어_YYYY-MM-DD.md`) (v0.2 원문 유지 + 상세 리포트 연결)

- 3~5개, 각 10줄 내외. 양식:

```markdown
### I-NN | 한 줄 제목   [태그: 재료치환 / 측정추가 / 조건확장 / 방법결합]
- 미해결 문제·미시도 방법: 한 문장
- 근거: [1] 저자, 저널 권(호), 쪽 (연도) — "원문 발췌 ≤15단어" (Sec./Fig. 위치)
- 제안 실험: 2~3문장 (재료·조건·측정)
- 논문 포인트: 기존 대비 새로운 점 1~2문장
- 필요 장비: ✔ 보유 / ✘ 미보유(→ 구매 제안 B-NN 참조 또는 대안) / ? 확인 필요
- 타겟 저널: 1~2개 (IF 0.5~4)
- 리스크: 한 문장
- 상세 리포트 (40p+ 설득 리포트 & 10p 논문 원고): [[_paper-scout/ideas/reports/Report_I-NN_{주제약칭}]]
- 채택? [ ] 진행 [ ] 보류 [ ] 폐기
```

- 규칙: 라이브러리에 없는 논문은 근거로 쓰지 않음. 추정은 "추정"으로 표기. 수치는 `numeric-check` 기준으로 원문 대조. 제시된 아이디어가 $N$개이면 반드시 아래 8절 규칙에 따라 개별 상세 리포트(`Report_I-01` ~ `Report_I-0N`) $N$개를 1:1로 생성함.

## 7. 구매 제안서 (`ideas/구매제안_YYYY-MM-DD.md`) (v0.2 원문 그대로 유지)

- 아이디어 보고서에서 ✘로 표시된 장비·물품 중 **구매 시 열리는 아이디어 수 / 가격** 비율이 높은 것만 추림(기본 최대 5건).
- 양식:

```markdown
### B-NN | 품목 (사양)   대략 가격: ~X 만원 (출처 링크, 조회일, 환율·견적 변동 주의)
- 왜 필요한가: 현재 ✘ 때문에 막혀 있는 아이디어 I-xx, I-yy
- 사면 이렇게 쓴다: 구매 → 이 측정/실험 가능 → 이런 논문 (타겟 저널) — 2~3문장
- 대안: 대여 / 저가 대체품 / 공동장비 (있으면)
- 우선순위: 상/중/하 (열리는 아이디어 수 ÷ 가격 기준)
- 검토? [ ] 견적 요청 [ ] 보류
```

- 가격은 웹 검색(제조사·대리점 공개가, 중고 시세)으로 범위로 제시. 확인 불가 시 "가격 미확인(견적 필요)"로 두고 지어내지 않음.
- `오늘할일.md` 1절에 "구매 제안 N건 검토 → [[링크]]"로 연결.

## 8. 주제별 상세 리포트 (`ideas/reports/Report_I-NN_*.md`) 및 10페이지 논문 원고 작성 규칙 [v0.3 신규]

요약 보고서(`아이디어_YYYY-MM-DD.md`)만으로는 근거가 짧아 AI가 할루시네이션(사기)을 치는지 알 수 없으므로, **제시한 각 주제별로 각각 하나씩 상세 리포트(`_paper-scout/ideas/reports/Report_I-NN_{주제약칭}.md`)를 생성**한다. (아이디어가 4개면 상세 리포트도 4개).

### 8.1 분량 기준 (최소 40페이지 이상) 및 무생략 작성 원칙
- 각 상세 리포트는 **Part A (심층 문헌 검증·생소한 개념 해설·차별성 설득 리포트: 최소 30페이지 분량)**와 **Part B (Optics Express 양식의 한국어 서술형 논문 원고: 최소 10페이지 분량)**를 합쳐 **최소 40페이지 이상**으로 매우 상세하게 작성한다.
- 단일 출력 길이 제한 때문에 내용을 요약하거나 생략하지 않으며, 섹션별 순차 파일 추가(Append)를 통해 40페이지 이상의 분량을 온전히 채운다.

### 8.2 `detail-references` 규칙 준수 (상세 원문 인용 및 팩트 검증)
- 본문의 모든 데이터, 물성치, 수치, 수식, 주장에 대해 본문 위에서 아래로 등장하는 순서(Ordered by appearance)에 따라 꺾쇠괄호 `[1]`, `[2]`, `[1, 2]` 형태로 인용 번호를 삽입한다(하이픈 `[1-3]` 표기 금지).
- 하단 `References` 목록에는 원문 서지 정보와 더불어, 사용자가 원문을 일일이 다시 열지 않고도 사기 여부를 즉시 확인할 수 있도록 **참고문헌 원문에서 해당 수치·수식·주장이 언급된 구체적인 문장, 수식, 표 데이터를 요약이나 의역 없이 원문 그대로(Verbatim) 길게 직접 발췌**하고 정확한 출처 위치(파일명, 페이지 `p. XX`, `Sec. X.X`, `Eq. (X)`, `Fig. X`, `Table X`)를 전수 기재한다.

### 8.3 이전 연구 결과 그림(Figure) 캡처 및 전용 폴더 관리
- 이전 연구 결과의 그림·그래프·실험 구성도를 인용하거나 비교해야 할 경우, 원본 PDF에서 해당 그림 영역을 고해상도 PNG(`300 DPI`)로 캡처하여 붙여 넣는다.
- 마크다운 파일을 열어도 캡처 그림이 깨지지 않고 그대로 유지되도록 **`_paper-scout/ideas/reports/figures/I-NN/` 폴더를 별도로 만들어 캡처본 이미지 파일을 저장·관리**하고, 리포트 마크다운 내에서는 상대 경로(`![캡션](figures/I-NN/파일명.png)`)로 연결한다.
- 캡처한 각 그림 아래에는 ① 원문 캡션 및 한국어 번역, ② 그래프의 가로·세로축과 각 곡선의 물리적 의미, ③ 해당 그림에서 확인되는 이전 연구의 한계점과 우리 아이디어가 이를 어떻게 돌파하는지에 대한 상세 해설을 작성한다.

### 8.4 Part A (심층 설득 리포트, 최소 30페이지) 필수 구성 항목
누군가가 리포트를 읽었을 때 *"음! 이렇게 하면 이전 연구결과와 차별성이 있어서 논문이 되겠군!"* 하고 즉시 납득할 수 있도록 다음 내용을 빠짐없이 포함한다:
1. **논문 성립 핵심 설득 요약 (Executive Conviction & Novelty Thesis)**:
   - 왜 이 주제가 논문이 되는지, 기존 연구들이 왜 이 문제를 못 풀었는지, 우리 연구실의 어떤 장비·아이디어 결합이 결정적 열쇠(Killer Idea)인지를 명쾌하게 제시함.
2. **생소한 개념 및 물리·수학적 원리 상세 해설 (Self-Contained Concept Tutorial)**:
   - 리포트에 등장하는 생소한 개념(광학 현상, 광섬유 모드 전파, 간섭계 전달함수, 신호처리 필터, 잡음 스펙트럼 등)이 무엇인지 읽으면서 막힘없이 이해될 수 있도록 기초 개념부터 중간 생략 없는 단계별 수식 유도(Step-by-step derivation), 기호·단위 정의표까지 교과서 수준으로 친절하게 해설함.
3. **선행 연구 전수 해부 및 원문 문구·캡처 그림 정밀 대조 (Exhaustive Prior-Art Analysis)**:
   - 관련 선행 연구들을 논문별로 하나씩 깊이 있게 다루며, 각 논문이 사용한 셋업(캡처 그림 첨부), 핵심 수식, 달성 수치(원문 문장 발췌), 그리고 저자가 인정한 한계점 또는 미해결 맹점(원문 발췌)을 철저히 분석함.
4. **이전 연구와의 1:1 차별성 매트릭스 및 정량적 시뮬레이션 비교 (Differentiation Proof)**:
   - 선행 연구들과 제안 아이디어를 모든 설계 축(광원, 파장, 지연선/광학계, 신호처리, 물리적 조건, 비용·난이도)에서 1:1로 비교하는 대형 비교표와 정량적 오차·성능 예측 계산을 제시함.
5. **보유 장비(`lab_inventory.md`) 기반 실험 프로토콜 및 저널 심사위원 방어 논리 (Reviewer Rebuttal Playbook)**:
   - 연구실 보유 장비만으로 즉시 수행 가능한 단계별 실험 매뉴얼과, 타겟 저널 심사위원이 제기할 수 있는 까다로운 질문 10선 및 문헌·실험 기반 모범 방어 논리를 수록함.
6. **Part A References 및 `detail-references` 원문 직접 발췌 전수 목록**.

### 8.5 Part B (10페이지 분량 한국어 서술식 논문 원고, *Optics Express* 양식) 작성 규칙
각 상세 리포트 후반부에는 **10페이지 분량의 완성형 논문 원고**가 반드시 포함되어야 한다:
1. **언어 및 문체 (한국어 서술식 필수 — 꼭지형식/음슴체 금지)**:
   - 논문 원고는 **한글로 작성하되, 꼭지형식(불릿 나열, 음슴체 `~음/~함`)이 아니라 실제 학술 논문을 읽는 것처럼 매끄럽게 이어지는 서술식 문장(`~한다`, `~이다`, `~로 나타난다`, `~을 확인하였다`)으로 작성**한다.
2. **전반적인 양식 (*Optics Express* 표준 구조 준수)**:
   - **Title (영문·국문 병기)** 및 **Authors & Affiliations**
   - **Abstract** (단일 문단 서술형 초록)
   - **1. Introduction (서론)** (연구 배경, 선행 연구 `[1]`, `[2]` 인용 및 한계, 본 논문의 기여점 서술)
   - **2. Theoretical Model and Operating Principle (이론적 모델 및 동작 원리)** (수식 유도 및 물리적 해석 서술)
   - **3. Experimental Setup and Measurement Procedure (실험 장치 및 측정 절차)** (연구실 보유 장비 모델명·사양을 반영한 서술)
   - **4. Experimental Results and Discussion (실험 결과 및 고찰)** (빈칸 채우기형 결과 서술 및 Figure 촬영 가이드 포함)
   - **5. Conclusion (결론)**
   - **Funding / Disclosures / Data Availability**
   - **References** (*Optics Express* 스타일 서지 + 원문 발췌)
3. **빈칸 채우기(Fill-in-the-Blank) 슬롯 및 데이터 그림 촬영 가이드**:
   - 실제 실험 후 수치만 채워 넣으면 바로 논문이 완성되도록, 측정 수치 자리에는 `[빈칸 #N: 측정 물리량 및 단위 — 이론 예상 범위: XX ~ YY]` 형태의 명확한 빈칸 슬롯을 배치한다.
   - 논문 원고에는 아직 실제 측정 데이터 그림이 들어가지 않으므로, 각 Figure(`Fig. 1` ~ `Fig. 6` 등)와 Table 자리에 **[Figure N 데이터 촬영 및 작성 가이드]** 박스를 삽입하여 **① 어떤 광학·장비 조건에서, ② 어떤 계측기 설정(RBW, VBW, 샘플링 속도, 레코드 길이, 평균 횟수 등)으로, ③ 무엇을 변화시키며 어떻게 찍은 무슨 데이터($x$축, $y$축, 단위, 비교 곡선 구성)가 들어가면 좋은지, ④ 데이터가 찍혔을 때 본문의 어느 빈칸을 어떻게 채워 해석하면 되는지**를 상세히 설명한다.

## 9. 자료 조사 진행 중(미수렴 시) 리포트 및 논문 원고의 동적 방향 수정 규칙 [v0.3 신규]

자료 조사가 계속 이어지는 동안(논문 개수가 아직 포화·수렴하지 않은 경우), 상세 리포트와 10페이지 논문 원고의 방향성은 새로 확보되는 논문에 맞춰 지속적으로 달라져야 한다:
1. **신규 논문 다운로드 시 상충 검사 (`[정리]` 단계 필수 수행)**:
   - 사용자가 새로 논문 PDF를 다운로드하면, 해당 논문의 내용을 분석하는 즉시 기존에 제시한 각 아이디어(`I-01` ~ `I-NN`), 상세 리포트(`Report_I-01` ~ `Report_I-NN`), 그리고 10페이지 논문 원고와 상충되는지 전수 대조한다.
2. **선행 보고(상충) 확인 시 리포트·원고 전면 갈아엎기 (Overhaul / Pivot)**:
   - 새로 다운로드한 논문이 기존에 제시한 아이디어와 겹쳐 이미 사전에 보고된 내용임이 확인되면, **기존 설득용 상세 리포트와 10페이지 논문 원고를 모두 갈아엎고**, 새로 발견된 논문의 한계(`gaps.md`)를 돌파하거나 우리 연구실 장비 조건에서만 가능한 새로운 차별성 방향으로 리포트와 원고를 전면 재작성한다.
3. **보강·확장 논문 확인 시 누적 업데이트**:
   - 새로 다운로드한 논문이 기존 아이디어의 이론적 근거를 보강하거나 비교 대조군으로 활용 가능한 경우, 상세 리포트의 선행 연구 분석 절, 캡처 그림, `detail-references` 인용 목록, 그리고 10페이지 논문 원고의 서론·이론·고찰에 즉시 반영하여 업데이트하고, 그 변경 이력을 리포트 상단 `Revision Log`와 `오늘할일.md` 3절에 기록한다.

# paper-scout

## 기본 규칙
1. 사람에게 묻거나 알리는 말은 전부 `<루트>/오늘할일.md`에만 씀. 채팅·다른 파일로 질문하지 않음. 다른 파일은 [[링크]]로만 연결.
2. `오늘할일.md` 맨 아래 `- [x] 제출`이 체크되어 있지 않으면 사람 입력에 의존하는 후속 작업(요청서 정리, 장비 DB 반영, 아이디어 채택 처리)을 하지 않음. 상태줄만 "🟡 입력 대기 (N회차)"로 갱신하고 종료. 재촉 문구 쓰지 않음.
3. 사람 입력이 필요 없는 작업(검색, 서지 확인, 이미 폴더에 있는 PDF 노트 작성, gaps 누적, 포화 지표 계산, 상세 리포트 보강)은 제출 여부와 무관하게 수행.
4. 모든 설정은 기본값으로 시작. 사람에게 선택을 요구하지 않음. 바꿀 수 있는 값은 `오늘할일.md` 4절에 보여주기만 함.
5. 근거는 library_index.md에 있는 논문의 원문 발췌(요약 보드는 ≤15단어 + 위치 표기, 상세 리포트는 `detail-references` 규칙에 따른 원문 문장·수식·표 직접 발췌 + 위치 표기)만 사용함. 추정은 "추정", 미확인은 "미확인". 가격·웹 정보는 출처 링크와 조회일 병기. 지어내지 않음.
6. 제출 전에는 `오늘할일.md` 1·2·5절(사람 입력 영역)을 수정하지 않음.
7. **[필수] 순수 마크다운(`.md`) 원본 업로드 규칙 (Google Docs 변환 원천 금지)**: Google Drive에 `.md` 파일을 생성할 때 `drive:create_file`의 `mime_type`을 `"text/markdown"`이나 `"text/plain"`으로 주거나 `text_content` 파라미터에 텍스트를 직접 넣으면, Google Drive가 파일명에만 `.md`를 남긴 채 내부 포맷을 구글 독스(`application/vnd.google-apps.document`)로 자동 변환해 버림. 따라서 모든 `.md` 파일(`오늘할일.md`, `config.md`, `notes/*.md`, `ideas/*.md`, `Report_I-NN_*.md` 등)은 반드시 ① 로컬 VM 작업 디렉토리에 `.md` 파일로 먼저 저장한 뒤, ② `drive:create_file` 호출 시 `text_content`는 비워 두고 `base64_content: "file:///절대경로/파일명.md"`와 **`mime_type: "application/octet-stream"`**을 사용하여 순수 마크다운 파일(`fileExtension: "md"`)로만 업로드해야 함.

  1. **전방위 양방향 인용망 일괄 탐색**: 조사가 질질 끌리지 않도록 1회차부터 모든 소주제(`S1`~`Sn`) 키워드 병렬 검색과 함께, 기존 보유 PDF 및 최신 리뷰 논문의 참고문헌(Backward Snowballing)과 피인용 논문(Forward Citation)을 한 번에 스캔하여 핵심 논문 풀을 일괄 포착함.

  3. **15시 다운로드 직후 당일 연쇄 스캔(Same-Day Chained Search)**: 사용자가 15시경 PDF를 다운로드하고 제출하면, 다음 날 09시까지 기다리지 않고 당일 `[정리]` 단계에서 신규 PDF의 References를 즉시 역추적하여 미발굴 핵심 인용 논문이 남아 있는지 확인함.

## 포화 판정
- progress_notes.md에 사이클별 신규 relevant 편수·중복률·소주제별 편수 기록.
- 기준 충족 시 조사 주 1회로 전환하고 [아이디어 및 상세 리포트] 실행.
- **[조기 포화(Fast-Track Convergence) 판정]**: 장기 기준(3사이클 연속 신규 ≤ 10사이클 평균 20% AND 중복률 ≥ 70%) 도달 전이라도, ① 각 소주제(`S1`~`Sn`)별 핵심 원전 및 최신 SOTA 논문이 최소 2~3편씩 확보되었고, ② 신규 다운로드 논문들의 핵심 관련 참고문헌 중 이미 라이브러리에 보유/검토된 비율(**인용망 수렴률, Citation Closure**)이 **80% 이상**에 도달하면 **즉시(2~3회차, 1~2일 내) 조기 포화로 판정**하여 불필요한 추가 다운로드 요청을 멈추고 상세 리포트·논문 원고 완성으로 전환함.

## 아이디어 및 주제별 상세 리포트 (40p+ 설득 리포트 & 10p 논문 원고)
1. **아이디어 요약 보고서 (`ideas/아이디어_YYYY-MM-DD.md`)**:
   - 3~5개, 각 10줄 내외, 고정 양식(문제/근거/제안 실험/논문 포인트/필요 장비 ✔✘?/타겟 저널/리스크/상세 리포트 링크/채택 체크). 태그: 재료치환·측정추가·조건확장·방법결합.
2. **구매 제안서 (`ideas/구매제안_YYYY-MM-DD.md`)**:
   - ✘ 장비 중 (열리는 아이디어 수 ÷ 가격) 상위 최대 5건. 양식(품목·사양 / 대략 가격+출처+조회일 / 왜 필요 / 사면 이렇게 쓴다→이런 논문 / 대안 / 우선순위 / 검토 체크). 가격 미확인 시 "견적 필요".
3. **주제별 개별 상세 리포트 (`ideas/reports/Report_I-NN_{주제약칭}.md`) — 아이디어가 N개면 상세 리포트도 N개**:
   - **분량**: 각 리포트당 **최소 40페이지 이상** (Part A 설득·검증 리포트 최소 30p + Part B 10p 논문 원고). 축약·생략 없이 섹션별 순차 작성으로 완성.
   - **`detail-references` 준수**: 본문 모든 주장·수치·수식에 등장 순서대로 `[1]`, `[2]`, `[1, 2]` 인용 번호 표기(하이픈 `[1-3]` 금지). 하단 References에 원문 문장·수식·표 데이터 직접 발췌(Verbatim) 및 위치(파일명, `p. XX`, `Sec. X.X`, `Eq. (X)`, `Fig. X`) 전수 기재.
   - **선행 연구 그림 캡처 및 폴더 관리**: 이전 연구 결과의 그림·그래프를 고해상도 PNG(`300 DPI`)로 캡처하여 `_paper-scout/ideas/reports/figures/I-NN/` 폴더에 별도 저장하고 마크다운 이미지 경로(`![캡션](figures/I-NN/파일명.png)`)로 연결해 마크다운 파일을 열어도 그림이 그대로 유지되도록 관리함.
   - **Part A (30p+ 설득 리포트) 필수 내용**:
     ① 왜 이것이 논문이 되는지 핵심 논증 요약
     ② **생소한 개념 상세 해설** (읽으면서 바로 이해될 수 있도록 기초 물리·수학적 직관부터 단계별 수식 유도 및 기호 정의표까지 친절히 설명)
     ③ 선행 연구 논문별 정밀 분석(원문 발췌 + 캡처 그림 해설)
     ④ 이전 연구와의 1:1 차별성 비교 매트릭스 및 정량 시뮬레이션 ("음! 이렇게 하면 이전 연구결과와 차별성이 있어서 논문이 되겠군!" 하고 납득할 수 있는 비교 논증)
     ⑤ 보유 장비(`lab_inventory.md`) 기반 실험 절차 및 예상 심사위원 반박 방어 Q&A
     ⑥ Part A References 및 `detail-references` 원문 발췌 목록
   - **Part B (10p 분량 한국어 서술식 논문 원고, *Optics Express* 양식)**:
     - **문체**: 한글로 작성하되, 꼭지형식(불릿 나열, 음슴체)이 아니라 **완결된 한국어 서술식 문장(`~한다`, `~이다`, `~로 나타난다`)**으로 작성함.
     - **양식**: *Optics Express* 표준 구조(`Title` → `Abstract` → `1. Introduction` → `2. Theoretical Model and Operating Principle` → `3. Experimental Setup and Measurement Procedure` → `4. Experimental Results and Discussion` → `5. Conclusion` → `Funding/Disclosures/Data Availability` → `References`).
     - **빈칸 채우기 및 데이터 촬영 가이드**: 미측정 수치 자리에는 `[측정값 기입: 예상 범위 XX ~ YY]` 빈칸을 두고, 실제 데이터 그림 자리(`Fig. 1`~`Fig. 6` 등)에는 **[Figure N 데이터 촬영 및 작성 가이드]** 박스를 넣어 **어떤 조건(광원, 광섬유, 커플러 등)에서 어떤 계측기 설정(RBW, 샘플링 속도, 레코드 길이 등)으로 어떻게 찍은 무슨 데이터가 들어가면 좋은지** 빈칸 채우기 방식으로 상세히 설명함.
4. 요약 보드, 개별 상세 리포트 $N$개, 구매 제안서를 `오늘할일.md` 1절에 링크함.
