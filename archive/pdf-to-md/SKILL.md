# pdf-to-md

업로드된 PDF에서 요청한 범위의 요점정리를 작성하고, 원문 Figure를 PNG로 잘라내어 `![](상대경로)`로 삽입한 마크다운 파일 + 관련 폴더를 사용자가 지정한 경로에 생성하는 스킬임.

## 핵심 원칙
0. **한국어 출력 강제 (최우선)**: 원문이 영어(또는 기타 외국어)여도 MD에 들어가는 모든 서술은 **한국어 음슴체로 번역/정리**해서 작성함. 영어 문장을 그대로 두거나 영어로 요약하지 않음. 세부 규칙과 예외는 Step 5의 "언어 규칙"을 따르고, 저장 직전 Step 5-2의 영어 잔존 검사를 반드시 통과해야 함.
1. **토큰 절약**: 이미지는 파일로만 저장하고 대화에 올리지 않음. 검증용으로만 최소한(contact sheet 1장 등) 확인함. base64 내장 금지.
2. **정확성**: Figure 번호·캡션·내용이 서로 일치해야 함. 못 찾았거나 불확실한 Figure는 임의로 만들거나 추측하지 말고 MD에 `> [!warning] Fig. N 추출 실패/불확실` 로 표시하고 최종 보고에 명시함.
3. **텍스트 읽기 범위**: 사용자가 특정 섹션/페이지만 지정하면 해당 부분만 읽음. 지정이 없으면 처음부터 끝까지 빠짐없이 읽음.

## Step 0. 사전 점검 (Pre-flight) — 작업 시작 전 반드시 수행

### 0-1. PDF 확인
- `Glob`으로 첨부 파일(`/mnt/user-data/uploads/` 및 작업 디렉토리 `*.pdf`)을 확인함.
- **PDF가 없으면 작업을 시작하지 말고** 아래처럼 안내 후 턴을 종료함:
  > PDF가 확인되지 않음. 채팅창에 PDF를 첨부한 뒤 요청사항을 다시 알려주면 됨.
- PDF가 여러 개면 파일 목록(파일명, 페이지 수)을 확인하고 각각 별도 MD로 처리함.
- 스캔본(텍스트 레이어 없음)이면 사용자에게 알리고 OCR 진행 여부를 물음.

### 0-2. 저장 경로 확인
- 사용자 메시지에 저장 경로가 명시되어 있는지 확인함 (예: `D:\research\notes`, `~/papers/notes`).
- **경로가 없으면 작업 전에 질문함** (AskUserQuestion 사용 가능하면 사용, 아니면 평문). 질문 시 아래를 함께 안내함:
  - 저장할 폴더 경로 (예: `notes/` 하위)
  - 데스크톱 앱에서 해당 폴더가 연결되어 있어야 로컬에 바로 저장 가능함 (미연결 시 `+` 메뉴 → Add folder)
  - 경로를 모르면 "작업 공간에 만들고 zip으로 받기"를 선택할 수 있음
- 로컬 경로가 지정되었는데 폴더가 연결되지 않은 경우: `enable__mcp__remote-devices__` 계열 도구/`device_request_folder_access`로 접근을 요청하고, 불가하면 사용자에게 폴더 추가를 안내함. 그때까지 임시로 작업 디렉토리에서 진행하고 마지막에 zip 전달로 대체할 수 있음.

### 0-3. 요청사항 확인
- 요점정리 범위(전체/특정 섹션), 그림 포함 범위(모든 Figure/지정 Figure)가 없으면 기본값을 **전체 요점정리 + 모든 Figure**로 두고, 그 사실을 한 줄로 알린 뒤 진행함. 0-1, 0-2가 모두 충족되면 추가 질문 없이 바로 시작함.
- 누락 항목이 여러 개면 **한 번의 메시지로 묶어서** 질문함.

## Step 1. 출력 구조

```
{저장경로}/
├── {연도}_{제1저자}_{제목키워드}.md      # 논문당 1개
├── figures/
│   └── {연도}_{제1저자}_{제목키워드}/
│       ├── fig1.png
│       ├── fig2a.png ...
└── index.md                               # 있으면 행 추가, 없으면 생성
```
- 파일명은 공백 없이 영문/숫자/언더스코어만 사용함 (옵시디언 호환).
- 메타데이터(연도, 제1저자, 제목)는 PDF 1페이지에서 확인함. 확인 불가 시 사용자에게 묻거나 `unknown`으로 두고 알림.
- MD 내 이미지 경로는 **MD 파일 기준 상대경로**: `![Fig. 1](figures/2024_Kim_TiSa/fig1.png)`

## Step 2. 텍스트 추출
- `pdftotext -layout` 또는 PyMuPDF(`fitz`)로 추출. 섹션 단위로 나눠 읽어 컨텍스트를 아낌.
- 수식은 LaTeX(`$...$`, `$$...$$`)로 옮기되 원문 수식 번호(Eq. N)를 유지함. 추출이 깨진 수식은 해당 페이지를 래스터화해 확인함.

## Step 3. Figure 위치 탐지 및 추출

도구는 PyMuPDF(`fitz`) 우선, 필요 시 `pdfplumber`, `pdftoppm`을 사용함. 미설치 시 `pip install --break-system-packages pymupdf`.

1. **캡션 탐색**: 각 페이지에서 `^(Fig\.?|Figure)\s*\d+` 패턴의 텍스트 블록(`page.get_text("blocks")`)을 찾아 Figure 번호 ↔ 페이지 ↔ 캡션 bbox를 매핑함. (Table은 사용자가 요청한 경우에만 처리)
2. **그림 영역 결정** (캡션이 그림 아래/위 어느 쪽인지 페이지마다 판정):
   - 임베디드 래스터: `page.get_images()` + `page.get_image_rects(xref)`로 bbox 확보.
   - 벡터 그래프: `page.get_drawings()` 경로들의 bbox를 캡션 인접 영역에서 클러스터링하고, 축 라벨·범례·(a)(b) 패널 라벨 등 그림에 속한 짧은 텍스트 블록을 포함시켜 하나의 영역으로 병합함.
   - 멀티패널(a, b, c…)은 **하나의 Figure로 묶어서** 저장함. 패널을 따로 요청받은 경우에만 분리함.
   - 영역은 사방으로 약 5~10pt 여백을 주되, 본문 단락/다른 Figure의 침범이 없도록 이웃 텍스트 블록 경계로 clamp함.
   - 2단 편집(two-column) 논문은 컬럼 폭 또는 전체 폭 Figure(`figure*`)를 구분함.
   - 캡션 본문 자체는 이미지에 포함하지 않음 (캡션은 MD에 한국어 텍스트로 작성).
3. **저장**: `page.get_pixmap(clip=rect, dpi=200)` → PNG. 파일명 `fig{N}.png` (패널 분리 시 `fig{N}a.png`). 극단적으로 큰 이미지(>2MB)는 dpi를 150으로 낮춤.
4. **페이지에 걸친 Figure, 부록(Supplementary) Figure, 회전된 페이지**는 별도로 확인하고 예외 처리함.

## Step 4. 검증 (토큰 최소화)
- 추출된 모든 PNG를 **하나의 contact sheet**(한 장에 썸네일 격자, 각 칸에 Fig 번호 라벨)로 합쳐 `Read` 한 번으로 확인함. Figure 수가 많으면 6~9개 단위로 나눔.
- 확인 항목: (a) 번호-내용 일치 (b) 가장자리 잘림 (c) 본문 텍스트/다른 그림 혼입 (d) 빈 이미지.
- 문제 있는 Figure만 bbox를 조정해 재추출하고 해당 건만 다시 확인함. 재시도는 Figure당 최대 2회, 이후에도 불확실하면 경고 표기로 처리함.

## Step 5. 마크다운 작성

### 5-1. 언어 규칙 (모든 외국어 → 한국어)
- **기본**: 요점정리 본문, 섹션 제목, 목록, 표 내용, Figure 캡션, 관련성, 요약 등 MD의 모든 서술을 **한국어 음슴체**로 작성함. 원문이 영어여도 영어 문장을 그대로 복사하거나 영어로 요약하지 않고, 의미를 이해한 뒤 한국어로 번역/정리함.
- **섹션 제목**: 한국어로 쓰고 필요하면 원어를 괄호 병기함. 예: `## 방법론 (Methods)`, `## 결과 (Results)`.
- **Figure 캡션**: 반드시 한국어 번역(또는 요약)으로 작성함. 영어 캡션을 그대로 붙이지 않음.
- **표(Table)·목록 항목**: 셀과 항목 내용도 한국어로 번역함. 수치·단위·기호는 그대로 둠.
- **전문 용어**: 최초 등장 시 `한글 번역(원어)` 병기, 이후에는 원어 또는 약어만 사용. 약어(SHG, GVD, OPA 등)는 최초 풀네임 병기 후 약어만 사용.
- **번역하지 않고 원문 그대로 두는 것(허용 예외)**: 저자명, 기관명, 저널명, 논문 제목(frontmatter의 `title`, `journal` 및 `# 제목` 헤더), 장비·제품 모델명, 화학식·변수·수식(LaTeX), 단위, 파일 경로, 코드, 위키링크 대상 이름, 이미지 파일명.
- **원문 직접 인용 (`인용 가능 문장`)**: 원문 15단어 이내를 따옴표로 그대로 쓰고, **바로 아래 줄에 한국어 번역을 반드시 병기**함. 원문 인용은 이 절에만 두고 본문 서술에는 쓰지 않음.
- 그림 내부(축 라벨, 범례 등)는 이미지라 번역 불가함. 필요하면 캡션 번역 뒤 `(그림 내 라벨은 원문 영어)` 정도로만 표기함.
- 단위는 SI 기본, 원문 단위는 괄호 병기. 그리스 문자·첨자는 원문 유지.

### 5-2. 영어 잔존 검사 (저장 직전 필수)
MD 작성 후 아래 스크립트(또는 동등한 검사)를 `Bash`로 실행하고, 걸린 줄은 한국어로 고쳐 쓴 뒤 다시 검사해 0건이 될 때까지 반복함.

```python
import re, sys
src = open(sys.argv[1], encoding='utf-8').read()
body = re.sub(r'^---.*?---', '', src, count=1, flags=re.S)   # frontmatter 제외
body = re.sub(r'```.*?```', '', body, flags=re.S)             # 코드블록 제외
body = re.sub(r'\$\$.*?\$\$|\$[^$]*\$', '', body, flags=re.S)  # 수식 제외
body = re.sub(r'!\[[^\]]*\]\([^)]*\)', '', body)              # 이미지 링크 제외
bad = []
for i, line in enumerate(body.splitlines(), 1):
    if line.startswith('# '):          # 논문 제목 헤더 허용
        continue
    if line.lstrip().startswith('- "') or line.lstrip().startswith('"'):   # 15단어 이내 원문 인용 허용
        continue
    if re.search(r'(?:[A-Za-z][A-Za-z\-]*[ ,]+){4,}[A-Za-z]+', line) and not re.search(r'[가-힣]', line):
        bad.append((i, line))
for i, l in bad:
    print(i, l)
print('영어 잔존 의심:', len(bad), '줄')
```

- 한글이 한 글자도 없고 영어 단어가 5개 이상 이어지는 줄을 영어 잔존으로 판정함. 그래도 한 문장이 영어 위주로 쓰였으면 한글 조사만 붙은 경우도 눈으로 점검해 고침.
- 예외(제목/인용/고유명사/수식)는 위 5-1의 허용 목록에 해당하는 것만 남김.

### 5-3. 템플릿
사용자가 별도 템플릿을 주지 않았다면 아래 구조를 사용함:

```markdown
---
title: "{원제}"
authors: [ ... ]
year: {연도}
journal: "{저널, Vol(Issue), 페이지}"
source_pdf: "{원본 파일명}"
---
# {원제}

## 연구질문 (RQ)
## 방법론
## 핵심 발견
### (사용자 요청 개념/섹션별 요점)
한국어 설명...

![Fig. 2](figures/{폴더}/fig2.png)
*Fig. 2. {캡션 한국어 번역 또는 요약}* (원문 p.N)

## 관련성 (내 연구와의 연결점)
## 인용 가능 문장
- "{원문 15단어 이내}" (p.N)
  - 번역: {한국어 번역}
```

- **각 Figure는 그것을 설명하는 본문 바로 아래에 배치**함. 해당 Figure를 참조하는 요점이 없으면 `## Figures` 절에 모아서 넣음.
- 모든 Figure 삽입에는 번호, 캡션(한국어 번역/요약), 원문 페이지를 포함함.
- 캡션·본문 장문 복제 금지, 번역/요약으로 처리함.
- 관련 논문/개념은 `[[위키링크]]` 문법을 사용함.
- 사용자가 요청한 개념/요점만 포함함 (요청 범위 밖의 내용을 늘리지 않음).

## Step 6. index.md 갱신
- 저장 경로에 `index.md`가 있으면 읽고 표에 행을 추가하고, 없으면 새로 만듦.
- 열: `제목 | 저자 | 연도 | 분류 | 파일경로`. 제목은 원제 유지, 분류 등 서술 항목은 한국어로 작성함. 같은 파일이 이미 있으면 중복 추가하지 않고 행을 갱신함.

## Step 7. 저장 및 전달
- **로컬 폴더가 연결된 경우**: 작업 디렉토리에서 완성한 뒤 device 도구(`device_commit_files` 등)로 지정 경로에 MD, `figures/`, `index.md`를 기록함. 기존 파일은 덮어쓰기 전에 사용자에게 확인함.
- **연결되지 않은 경우**: 같은 구조를 zip으로 묶어 `SendUserFile`로 전달하고, 지정 경로로 옮기는 방법 또는 폴더 연결 방법을 한 줄로 안내함.
- 결과 MD 1개는 `SendUserFile`로 함께 전달해 바로 확인할 수 있게 함.
- 작업이 끝나면 `progress_notes.md`가 저장 경로에 있으면 처리한 논문과 다음 할 일을 갱신함 (없으면 만들지 않고 넘어감).

## Step 8. 최종 보고 (간결하게, 한국어)
다음만 짧게 알림:
- 생성한 MD 파일명, 저장 위치
- 추출한 Figure 수 / 전체 Figure 수
- 한국어 변환 점검 결과 (영어 잔존 0건 확인)
- 경고 표시한 Figure(추출 불확실·실패)와 그 사유
- 필요 시 다음 단계 한 가지 (예: 불확실 Figure 수동 확인)

## 하지 말 것
- PDF나 저장 경로 확인 없이 작업 시작
- 추출한 이미지를 대화에 대량 출력/첨부
- base64 이미지 내장
- Figure를 임의로 재그리거나 다른 그림으로 대체
- 원문 단락/캡션을 영어 그대로 복사하거나 영어로 작성 (허용 예외 목록 제외)
- 5-2 영어 잔존 검사 없이 저장
- 사용자가 요청하지 않은 DOCX/PPTX 생성
