# 보고 양식

한국어, `-` 꼭지, 음슴체(~함, ~임)로만 씀. 숫자는 명령 결과에서 가져옴 (기억·추측 금지).

## 시작 보고 (3단계, 1회)

```
- 시작 전 상태: 남은 문서 N개 · 빈 칸 N개 (STATUS.md 첫 줄 기준)
- 이번 범위: 문서 1개 완료까지 / 전부
```

## 문서별 보고 (8단계, 문서 하나 끝날 때마다)

```
- 문서: <doc_id> <md 파일명>
- 채운 칸: 번역 N · 요약 O/X · 서지 N
- 검사: 통과 / 문제 N
- 남은 문서: N
```

- `요약`: 요약 칸을 썼으면 `O`, 책이거나 요약 칸이 없으면 `X`.
- `검사`: `--check <문서>` 종료 코드 0 이면 `통과`. 1 이면 `문제 N` 과 메시지 원문을 다음 줄에 덧붙임. 명령 없는 모드면 `미실행 (RUN.bat 실행 필요)`.
- `남은 문서`: 마지막 `--todo` 결과 기준.

## 건너뛴 문서가 있을 때 (덧붙임)

```
- 건너뜀: <문서> (찾을 수 없음, 종료 코드 2)
```

## 예시

```
- 문서: D335259a3 2024_Kim_QSwitch.md
- 채운 칸: 번역 87 · 요약 O · 서지 2
- 검사: 통과
- 남은 문서: 4
```
