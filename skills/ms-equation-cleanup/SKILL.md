# ms-equation-cleanup

Word·PowerPoint 문서에서 텍스트로 대충 적힌 수식을 **수식 개체**(Office Math, 수식 탭으로 입력한 것과 동일하게 Word/PowerPoint 에서 더블클릭해 편집 가능)로 바꾸는 스킬임. `^`, `_` 같은 타이핑 표기가 최종 문서에 남지 않게 하는 것이 목표임.

원리: Claude 가 문서의 수식 후보를 읽고 각 수식을 LaTeX 로 옮겨 적으면, `scripts/eqfix.py` 가 pandoc 으로 LaTeX 를 Office 수식 XML 로 변환해 원래 글자 자리에 끼워 넣음. 수식 XML 을 손으로 쓰면 틀리기 쉬우므로 반드시 스크립트를 거침.

필요 도구: `python3`, `lxml`, `pandoc`. (없으면 `pip install lxml`, pandoc 은 https://pandoc.org/installing.html)

## 절차

### 1. 스캔

```bash
python scripts/eqfix.py scan 문서.docx -o scan.json
```

수식 후보가 있는 문단만 `para`(문단 ID), `text`(raw 텍스트)로 출력됨. 후보 판정은 단순 규칙이라 놓칠 수 있으므로, 문서가 길지 않으면 `--all` 로 전체 문단을 받아 직접 훑는 것이 안전함.

- `marked` 가 있으면 이미 위/아래첨자 서식이 걸린 글자가 있다는 뜻임 (`x^{2}` 처럼 표시). `find` 에는 `text`(raw) 쪽 문자열을 써야 함.
- `existing_equation_objects`: 이미 수식 개체인 것. 건드리지 않음.
- `legacy_ole_equations`: 구형 수식 편집기 개체. 자동 변환 대상이 아니므로 개수만 보고함.
- pptx 문단 ID 는 `s3/p5`(3번 슬라이드), 슬라이드 노트는 `n3/p0`, docx 각주·머리글은 `footnotes/p2` 형태임.

사용자가 범위(특정 절, 슬라이드, 선택 영역)를 지정했으면 그 범위의 문단만 처리함.

### 2. plan.json 작성

후보마다 아래 셋 중 하나로 분류해 plan 을 작성함.

| 분류 | 대상 | plan 키 |
|---|---|---|
| 수식 개체 | 변수·등식·함수·연산이 들어간 수학 표현 (`E = mc^2`, `n_eff`, `x2 + y2 = 1`, 본문 속 단독 변수 `w_0` 포함) | `latex` |
| 위/아래첨자 서식 | 수식이 아닌 일반 텍스트의 첨자: 단위(`cm^-1`), 화학식(`TiO_2`), `Nd^3+`, `1st` 등 | `rich` |
| 그대로 둠 | 참고문헌 번호, 파일명·URL·코드·변수명에 쓰인 `_`, 이미 수식 개체인 것 | (plan 에 넣지 않음) |

```json
[
  {"para": "p12", "find": "E(r) = E_0 exp(-r^2/w_0^2)", "latex": "E(r)=E_{0}\\exp\\left(-\\frac{r^{2}}{w_{0}^{2}}\\right)"},
  {"para": "p14", "find": "P_out = eta (P_in - P_th)", "latex": "P_{\\mathrm{out}}=\\eta\\left(P_{\\mathrm{in}}-P_{\\mathrm{th}}\\right)", "display": true},
  {"para": "p20", "find": "cm^-1", "rich": "cm^{-1}"}
]
```

- `find`: 해당 문단 raw 텍스트의 부분 문자열과 글자 단위로 정확히 일치해야 함 (공백 포함). 같은 문자열이 한 문단에 여러 번 나오면 `"nth": 2` 로 지정함.
- `display: true`: 문단 전체가 수식 하나일 때 가운데 정렬 독립 수식으로 넣음. 문단에 다른 글자(수식 번호 `(3)` 등)가 남으면 자동으로 줄 안 수식이 되고 나머지 글자는 그대로 보존됨.
- `rich`: `^{..}` 위첨자, `_{..}` 아래첨자. 글꼴·크기는 원래 글자 것을 유지함.
- JSON 안에서 백슬래시는 `\\` 로 두 번 적어야 함.

LaTeX 작성 규칙 (물리·광학 문서 기준):

- **내용을 바꾸지 않음.** 기호·수치·부호·항의 순서는 원문 그대로 옮기고, 오타로 보이는 것도 고치지 말고 보고서에 따로 적음. 수식 해석이 모호하면(예: `a/b c` 의 분모 범위) 추측으로 확정하지 말고 원문 형태를 유지한 채 "확인 필요"로 보고함.
- 풀어 쓴 그리스 문자(`lambda`, `pi`, `sigma`, `nu`)는 기호(`\lambda` …)로 바꿈.
- 변수는 이탤릭, **여러 글자짜리 설명 첨자·단위·함수명은 정체**로 적음: `n_{\mathrm{eff}}`, `P_{\mathrm{th}}`, `1550\ \mathrm{nm}`, `\exp`, `\sin`. 변수 역할을 하는 한 글자 첨자(`E_{0}`, `N_{2}`, `k_{x}`)는 그대로 둠.
- 독립 수식의 분수는 `\frac{}{}`, 줄 안의 짧은 분수는 원문이 `/` 이면 `/` 유지 가능. 곱셈 `*` 는 문맥에 맞게 `\cdot` 또는 `\times`, `sqrt(x)` 는 `\sqrt{x}`, 키가 큰 괄호는 `\left( \right)`.
- 수와 단위 사이는 `\ ` 로 띄움. 단위가 수식 밖 본문에 있으면 수식에 끌어넣지 않아도 됨.
- 이미 서식으로 위첨자가 걸린 수식(`marked` 에 보이는 `x^{2}`)도 수식 개체로 통일함.

### 3. 적용

```bash
python scripts/eqfix.py apply 문서.docx plan.json
```

원본은 수정하지 않고 `문서_eq.docx` 를 새로 만듦 (`-o` 로 이름 지정 가능). 실패 항목은 사유와 함께 출력되므로 plan 을 고쳐 **원본에 대해** 다시 실행함 (결과물에 덧칠하지 않음).

### 4. 검증

```bash
python scripts/eqfix.py check 문서_eq.docx
```

1. `residual_paragraphs` 에 남은 `^`, `_`, `\명령`, `$..$` 가 의도적으로 남긴 것(파일명 등)인지 확인함.
2. plan 의 `find` ↔ `latex` 를 한 줄씩 다시 대조해 첨자·부호·지수·괄호가 원문과 같은지 검산함. 수식은 한 글자 차이로 뜻이 달라지므로 이 단계를 생략하지 않음.
3. 가능하면 눈으로 확인: `soffice --headless --convert-to pdf 문서_eq.docx` 후 PDF 를 이미지로 봄. 단, LibreOffice 는 수식 모듈(`libreoffice-math`)이 있어야 Word 수식이 보이고, 글꼴·괄호 모양이 실제 Office 와 다름. **pptx 는 LibreOffice 가 수식을 못 읽어 원래 텍스트(호환용 사본)를 보여 주므로** 미리보기로 판단하지 말고 PowerPoint 에서 확인하도록 안내함.

### 5. 보고

결과 파일 경로와 함께 아래 표를 제시함. 대화창에는 요약만, 항목이 많으면 표를 `.md` 파일로 저장함.

| 위치 | 원문 | 변환 | 종류 |
|---|---|---|---|
| p12 | `E_0 exp(-r^2/w_0^2)` | $E_{0}\exp\left(-\frac{r^{2}}{w_{0}^{2}}\right)$ | 수식 개체 |

표 아래에 (a) 그대로 둔 항목과 이유, (b) 확인 필요 항목(해석 모호·오타 의심), (c) 구형 수식 개체/그림 수식 개수를 적음.

## 알아둘 점

- **pptx 는 수식 변환을 마지막에 수행함.** PowerPoint 방식대로 수식이 든 도형을 호환 블록(수식 도형 + 구버전용 원문 텍스트 사본)으로 감싸기 때문에, 변환 후에는 python-pptx 가 그 도형을 찾지 못함. 문구 수정·레이아웃 작업을 먼저 끝낸 뒤 변환함.
- 수식 글꼴은 Cambria Math, 크기·색은 원래 글자 것을 물려받음.
- 하이퍼링크나 변경 내용 추적 경계에 걸친 구간은 스크립트가 거부함. 그 부분만 수동 처리 대상으로 보고함.
- 그림으로 박힌 수식을 수식 개체로 바꾸는 것은 사용자가 요청할 때만 진행하고, 그림에서 읽은 LaTeX 를 먼저 보여 준 뒤 확인을 받음 (판독 오류 위험).
- 새 문서를 만들 때는 수식 자리에 임시 표식(예: `[[EQ1]]`)을 넣어 문서를 만든 뒤, 표식을 `find` 로 지정해 같은 방식으로 수식 개체를 삽입함.
