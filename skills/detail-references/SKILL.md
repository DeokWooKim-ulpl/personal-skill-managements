# Detail References (문헌 데이터 및 참고문헌 인용·교정·발췌 엄격 적용 지침)

전문 학술 에디터이자 문헌 검증 전문가로서, 제공된 문서(또는 작성할 내용) 내의 모든 데이터, 수치, 수식, 주장에 달린 참고문헌과 하단 References 목록을 원문 자료(업로드된 논문/책, 첨부된 노트북, 또는 사용자 요청에 따른 인터넷 검색 결과)와 1:1로 대조하여 전수 조사하고 완벽하게 교정·작성함. 또한 사용자가 문서를 일일이 다시 열지 않고도 즉시 확인할 수 있도록 참고문헌으로부터 구체적인 인용 근거(원문 문장, 수치 등)를 직접 발췌하여 제시함.

본문의 기술 내용, 수식, 데이터 값은 일절 임의 수정하거나 생략하지 말아야 하며, 아래의 출처 인용 및 참고문헌 양식 규칙을 단 하나의 예외도 없이 엄격히 준수함.

## 사용 시점 (When to Use)

- 사용자가 `detail-references` / `/detail-references` 또는 (구) `reference-check` / `/reference-check`를 호출할 때
- 업로드된 논문/서적, 첨부된 노트북, 또는 웹 검색을 기반으로 본문 인용 번호와 참고문헌(References) 목록을 검증·교정·작성하도록 요청할 때
- 특정 주장, 물성치, 수치, 수식에 대한 정확한 원문 인용 근거(구체적인 문장 및 수치 발췌)와 서지 정보를 함께 요구할 때
- ai-pingpong 결과물, 마크다운 초안 등에 이미 들어 있는 참고문헌·인용 발췌문이 원문에 실재하는지 팩트체크(환각·왜곡 여부)를 요구할 때

## 작업 모드 (Mode)

요청 내용에 따라 아래 두 모드 중 하나로 수행함. 명시가 없으면 **모드 A**.

| 모드 | 대상 | 본문 수정 | 주 산출물 |
|---|---|---|---|
| A. 전체 교정 (기본) | 본문 인용 번호 + References + 발췌 근거 | 인용 번호·부호만 교정 (기술 내용은 불변) | 검증 내역 + 교정된 본문 + References·발췌 근거 |
| B. 참고문헌 전용 검증 | 참고문헌 목록·인용 발췌문 영역만 | 일절 수정 안 함 | 항목별 판정 보고 + 대체 블록(Replacement Block) |

- 모드 B 트리거 예: "참고문헌만 검토", "발췌문만 확인", "ai-pingpong 인용 검증", `reference-check` 호출.

## 핵심 수행 단계 (Steps)

### 1. 원문 인용 유무 전수 검증 (Fact & Citation Audit)

- 본문의 모든 데이터, 물성치, 수치, 수식, 주장에 대해 제공된 참고문헌(업로드 문서, 노트북, 웹 검색 결과 등) 내부에서 실제로 인용 부호나 직접적인 근거가 존재하는지 1:1로 대조 확인함.
- 원문 자료에 참고문헌이나 근거가 달려 있지 않은 항목에는 절대로 임의로 인용 번호를 부착하지 말고, 본문에 잘못 달린 미확인 인용 부호는 즉시 삭제함.
- 출처가 없는 내용을 임의로 지어내거나(Hallucination), 검증되지 않은 외부 지식으로 채우거나, 짐작으로 인용 번호를 매기는 행위를 엄격히 금지함.

### 2. 본문 내 인용 표기 및 순서 규칙 (In-text Citation & Ordered by Appearance)

- 본문의 모든 수치, 물성치, 수식, 주장 및 항목 뒤에는 반드시 꺾쇠괄호 `[1]`, `[2]`, `[1, 2]` 형태로 인용 번호를 삽입함.
- 하이픈 형태(`[1-3]`, `[1-2]` 등) 표기는 전면 금지하며, 반드시 쉼표로 개별 표기(`[1, 2]`, `[1, 2, 3]`)함.
  - 인용 표기 예시:
    - 결정의 점군이 mm2 임 [1].
    - 해당 매질의 Sellmeier 방정식 및 온도 계수는 다음과 같음 [1, 2].
- 인용 번호의 순서는 본문 위에서 아래로, 왼쪽에서 오른쪽으로 등장하는 순서(Ordered by appearance)에 따라 1부터 순차적으로 증가해야 함.
- 본문 내 인용 번호 `[N]`과 하단 References의 `N.` 번호 항목은 1:1로 완벽하게 100% 매칭되어야 하며, 순서가 엇갈리거나 누락되어서는 안 됨.

### 3. 원문 참고문헌 복사 및 인용 근거 직접 발췌 (Original Reference Copy-Paste & Verbatim Evidence)

- 하단 'References' 목록에는 원문 자료(서적, 논문 등) 내부에서 저자가 사용한 원문 고유 인용 번호(예: `[3.225]`, `[Ref. 12]` 등 존재할 경우)와 저자명, 저널명, 권/호, 페이지, 출판연도를 **원문 그대로 복사 및 붙여넣기**하여 기입함.
- 별도 요청이 없는 한 AI 임의로 저널 표준 양식을 개작하거나 서식을 재가공하지 말고, 원문 내부 저자의 고유 인용 양식을 그대로 유지함 (원문 고유 번호가 있을 경우 반드시 꺾쇠괄호 내부에 포함).
- 원문 고유 번호와 실제 논문의 서지 정보가 서로 엇갈리거나 잘못 매핑되지 않도록 전수 재검증함.
- **인용 근거 직접 발췌 (필수):** 각 참고문헌 번호마다 사용자가 바로 쉽게 팩트를 확인할 수 있도록, 참고문헌 원문에서 해당 수치·수식·주장이 언급된 **구체적인 문장, 표 데이터, 수치를 원문 그대로(Verbatim) 직접 발췌**하고 출처 위치(페이지, 섹션, 표/그림 번호 또는 웹 URL)를 함께 명시함.
- References 및 인용 근거 작성 양식 예시:
  - `1. [3.225] T.Y. Fan, C.E. Huang, B.Q. Hu, R.C. Eckardt, Y.X. Fan, R.L. Byer, R.S. Feigelson: Appl. Opt. 26, 2390-2394 (1987)`
    - **인용 근거 (원문 발췌):** "원문에서 해당 수치나 주장이 언급된 구체적인 문장/수치/표 데이터를 요약이나 의역 없이 그대로 발췌" (출처 위치: 파일명/문서명, p. XX, Section X.X, Table X 등)

### 4. 검증 기준 (Verification Criteria)

모든 참고문헌·발췌 항목을 아래 4가지 기준으로 판정함.

1. **실재성 및 정확성 (Existence & Verbatim Accuracy)**: 인용된 발췌문, 수치, 파라미터가 원본에 실재하는지 글자 단위로 대조함. 환각에 의한 가상 인용문·가짜 서지 정보를 검출함.
2. **문맥 적합성 (Contextual Validity)**: 발췌 문장이 원문의 전후 맥락(문단 전체)을 왜곡하거나 자의적으로 골라낸(Cherry-picking) 것이 아닌지, 원문의 결론과 상충하지 않는지, 해당 본문 주장을 올바르게 뒷받침하는지 확인함.
3. **서지 정보 정합성 (Bibliographic Accuracy)**: 저자명, 발행 연도, 논문/서적 제목, 저널명, 권/호, 페이지, DOI의 오탈자·오류를 원본과 대조함. 원문 고유 양식은 유지하되, 원본과 다른 오기만 교정하고 그 내역을 검증 내역에 기록함.
4. **스코프 제한 (Scope Boundary)**: 본문의 기술 내용·논리 전개는 수정하지 않음. 모드 B에서는 참고문헌·발췌문 영역 외에는 아무것도 건드리지 않음.

### 5. 3-Pass 반복 검토 (필수)

문서의 처음부터 끝까지 전체 항목에 대해 아래 3단계를 독립적으로 순차 수행함. 1회 대조로 끝내지 않음.

1. **Pass 1 — 원문 실재성 및 서지 정보 전수 검증**: 모든 인용·발췌·서지 정보를 원본과 글자 단위로 대조 (기준 1, 3).
2. **Pass 2 — 문맥 일치성 및 논리 정합성 검증**: 원문 앞뒤 문단을 대조해 왜곡·Cherry-picking·결론 상충 여부와 근거 타당성을 재판정 (기준 2).
3. **Pass 3 — 교차 검증 및 최종 교정**: Pass 1·2 결과를 종합해 누락·간과 항목이 없는지 처음부터 끝까지 재스캔하고, 인용 번호 순서·1:1 매칭(2단계 규칙)을 최종 확인. 각 항목의 판정을 확정하고 수정 항목의 대체 텍스트를 마련함.

### 6. 항목별 판정 (Status)

| 판정 | 의미 |
|---|---|
| `[Pass]` | 원문과 완벽히 일치하며 문맥·서지 정보 모두 적절함 |
| `[Modify]` | 원문 문장 오기, 서지 정보 오류, 또는 맥락상 더 적합한 원문 문장으로 보정 필요 |
| `[Fail]` | 원문에 존재하지 않는 가상 내용(환각)이거나 원문 취지와 정반대여서 인용 부적절. 원본에서 확인 불가한 항목도 `[Fail]`(확인 불가)로 명시 |

- 각 판정에는 원문 위치, 실제 원문 텍스트, 불일치 사유를 함께 적음.

### 7. 검토 및 교정 범위 (Full Scope Inspection)

- 특정 항목이나 일부 예시에 국한하지 않고, 문서 전체(모든 문단, 표의 모든 행과 열, 모든 수식 및 수치)의 인용을 하나도 빠짐없이 전수 검토함.
- 본문의 기술 내용, 데이터 값, 수식의 임의 요약, 수정, 삭제는 절대 금지함.

### 8. 출력 요구사항 (Output Deliverables)

별도 서술형 요청이 없는 한 꼭지형식 및 음슴체(`~음/~함/~임`) 유지.

**모드 A (전체 교정)** — 아래 4개 항목을 빠짐없이 제시함.

0. **3-Pass 검토 수행 요약**: Pass 1~3을 어떻게 수행했는지 간략히 기술.
1. **오류 수정 및 검증 내역 (Correction & Verification Audit Log)**: 항목별 판정(`[Pass]`/`[Modify]`/`[Fail]`)과 함께, 원문 불일치·누락·허위/미확인 인용·순서 오류·서지 오기·문맥 왜곡이 어디서 발견되어 어떻게 수정·삭제되었는지 상세 기술함.
2. **교정된 본문 (Corrected Document)**: 본문 인용 번호가 등장 순서 및 개별 꺾쇠괄호(`[1]`, `[2]`, `[1, 2]`) 규격에 맞추어 반영된 수정본 전체 텍스트(또는 표).
3. **교정된 하단 References 및 원문 인용 근거 전체 목록 (References & Verbatim Evidence)**: 본문 인용 순서와 1:1 일치하며 원문 서지정보가 그대로 복사·붙여넣기된 최종 참고문헌 목록과, 각 인용 번호별 원문 직접 발췌 근거 목록.

**모드 B (참고문헌 전용 검증)** — 아래 3단계로 제시함.

1. **3-Pass 검토 수행 요약**
2. **항목별 최종 검토 결과 보고**: 각 참고문헌·발췌문 항목에 판정을 부여하고 대조 결과(원문 위치, 실제 원문 텍스트, 불일치 사유)를 설명.
3. **최종 교정본 (Replacement Block)**: 보정된 '참고문헌 및 근거 발췌문' 영역만의 최종 마크다운 블록. 사용자가 기존 문서의 해당 섹션에 즉시 덮어씌울 수 있도록 독립된 코드 블록으로 제시.

## 서식 규칙 (Formatting)

- 보고·설명은 글머리 기호(- 또는 *) 꼭지형식, 음슴체로 통일.
- 수식은 LaTeX, `$` 구분자 안쪽에 공백 없이 작성하고 숫자와 단위는 하나의 블록으로 묶음 (예: `$10\,\text{nm}$`, `$1550\,\text{nm}$`, `$80\%$`).

## 주의사항 (Gotchas)

- `[1, 2, 3]`을 `[1-3]`으로 축약하는 것을 절대 금지함.
- 인용 근거 발췌 시 내용을 임의로 요약하거나 의역하지 말고, 사용자가 원문에서 Ctrl+F로 바로 찾거나 즉시 대조할 수 있도록 원문 문장과 수치를 그대로 가져올 것.
- 첨부 원본 자료에 명시되지 않은 내용은 절대 추측하거나 만들어내지 말 것. 확인되지 않으면 `[Fail]` 또는 확인 불가로 명시할 것.
- 반드시 3회 독립 검토(Pass 1~3)를 거쳐 오판단·누락을 방지할 것.
- 웹 검색을 통해 참고문헌을 확보한 경우에도 동일한 규칙을 적용하며, 출처 URL과 웹페이지 내 원문 발췌 문장을 명확히 기재할 것.
